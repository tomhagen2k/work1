# Quy tắc thêm -s và -es (Danh từ số nhiều & Động từ số ít)

## 1. Nguyên tắc cơ bản
- Hầu hết các danh từ đếm được (khi chuyển sang số nhiều) và động từ (đi với chủ ngữ ngôi thứ 3 số ít: He, She, It) đều thêm **-s**.
  - Ví dụ: *cat -> cats*, *book -> books*, *run -> runs*.

## 2. Các trường hợp thêm -es
Thêm **-es** đối với các từ có chữ cái tận cùng là: **-o, -s, -z, -ch, -x, -sh** (Thần chú dễ nhớ: *O Sáu Zà Chạy Xe SH*).
- **-o**: *tomato -> tomatoes*, *go -> goes* (Ngoại lệ mượn từ nước ngoài: *piano -> pianos*, *photo -> photos*)
- **-s**: *bus -> buses*, *miss -> misses*
- **-z**: *buzz -> buzzes*
- **-ch**: *watch -> watches*, *catch -> catches*
- **-x**: *box -> boxes*, *fix -> fixes*
- **-sh**: *dish -> dishes*, *wash -> washes*

## 3. Quy tắc với chữ -y
- Nếu từ tận cùng là **Phụ âm + y**: Đổi `y` thành `i` và thêm `-es`.
  - Ví dụ: *baby -> babies*, *study -> studies*, *fly -> flies*.
- Nếu từ tận cùng là **Nguyên âm (u, e, o, a, i) + y**: Giữ nguyên `y` và thêm `-s`.
  - Ví dụ: *boy -> boys*, *play -> plays*, *buy -> buys*.

## 4. Quy tắc với chữ -f / -fe
- Đa số các từ tận cùng bằng **-f** hoặc **-fe**, ta đổi thành **-ves**.
  - Ví dụ: *leaf -> leaves*, *wife -> wives*, *thief -> thieves*, *wolf -> wolves*.
  - (Ngoại lệ: *roof -> roofs*, *cliff -> cliffs*, *chef -> chefs*).

> **Lưu ý**: Cần phân biệt rõ, với DANH TỪ thì thêm s/es là biến thành số nhiều, nhưng với ĐỘNG TỪ thì thêm s/es lại là chia cho chủ ngữ số ít (He/She/It).
